# 🍽️ Food Calories Prediction

##  Описание проекта

Цель проекта — предсказание калорийности блюда на основе:

* ингредиентов
* массы блюда
* изображения блюда

Проект реализует мультимодальную модель (табличные данные + изображения).

---

##  Данные

Используются следующие файлы:

* `dish.csv` — информация о блюдах
* `ingredients.csv` — справочник ингредиентов
* `images/` — изображения блюд

---

##  Подход

### 1. EDA

* анализ распределения калорий и массы
* выявление выбросов
* анализ зависимости массы и калорий

### 2. Признаки

* multi-hot encoding ингредиентов
* нормализация массы
* изображения (resize + tensor)

### 3. Модель

Мультимодальная архитектура:

* CNN для изображений
* MLP для табличных данных
* объединение признаков

---

##  Результаты

* Train MAE: ~35
* Test MAE: ~50

Модель показывает хорошее качество и улучшение по сравнению с табличной версией.

---

##  Анализ ошибок

Основные причины:

* сложные блюда с большим количеством ингредиентов
* влияние способа приготовления
* скрытые калории (масло, соусы)
* ограниченная выразительность модели

---

##  Как запустить

1. Установить зависимости:

```

```

2. Запустить notebook:

